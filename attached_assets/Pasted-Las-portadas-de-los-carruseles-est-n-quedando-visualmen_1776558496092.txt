PASO 1: CREAR UN BANCO DE POSES PARA PORTADAS

En el código del generador de carruseles, crear un array con 10-12 
poses/reacciones distintas que el zorro puede adoptar en la slide 1 
(portada). Cada pose debe describir:
- Posición del cuerpo (frontal, 3/4 izquierda, 3/4 derecha, perfil)
- Expresión facial (curiosidad, sorpresa, confianza, pensativo, 
  preocupación, alegría, shock)
- Gesto de brazos/manos (cruzado, señalando, mano en mentón, brazos 
  arriba, sosteniendo algo, shrug)
- Interacción con elementos de la escena

PASO 2: SELECCIÓN INTELIGENTE DE POSE SEGÚN EL TEMA

Al generar una portada, NO usar pose aleatoria pura. Mapear según 
el tipo emocional del tema:

```javascript
function seleccionarPosePortada(tema) {
  // Extraer emoción dominante del tema
  const emocion = detectarEmocion(tema);
  
  const posesPorEmocion = {
    pregunta: ["thinking_hand_chin", "shrug_confused", "whispering_secret"],
    problema: ["worried_head_hold", "shocked_front", "shrug_confused"],
    revelacion: ["shocked_front", "pointing_right", "pointing_left"],
    confianza: ["arms_crossed_confident", "thumbs_up_confident", "presenting_with_hand"],
    celebracion: ["triumphant_arms_up", "thumbs_up_confident"],
    educativo: ["presenting_with_hand", "reading_document", "pointing_right"],
    alerta: ["shocked_front", "worried_head_hold", "pointing_left"]
  };
  
  const posesCompatibles = posesPorEmocion[emocion] || 
                           Object.values(posesPorEmocion).flat();
  
  // Seleccionar una aleatoriamente del subset compatible
  return posesCompatibles[Math.floor(Math.random() * posesCompatibles.length)];
}

function detectarEmocion(tema) {
  const temaLower = tema.toLowerCase();
  
  if (/\?|por qué|cómo|qué|cuándo/.test(temaLower)) return "pregunta";
  if (/error|problema|falla|pierde|riesgo|peligro/.test(temaLower)) return "problema";
  if (/secreto|revelo|descubre|verdad|nadie/.test(temaLower)) return "revelacion";
  if (/confía|garantía|experto|profesional/.test(temaLower)) return "confianza";
  if (/éxito|logra|triplica|resultados|conseguir/.test(temaLower)) return "celebracion";
  if (/aprende|guía|pasos|tutorial|razones/.test(temaLower)) return "educativo";
  if (/urgente|cuidado|importante|atención/.test(temaLower)) return "alerta";
  
  return null; // Fallback a cualquier pose
}
```

PASO 3: MEMORIA DE ÚLTIMAS POSES USADAS (ANTI-REPETICIÓN)

Guardar las últimas 3-5 poses usadas en portadas recientes. Al 
seleccionar una nueva pose, EXCLUIR las que ya se usaron 
recientemente.

```javascript
// En la DB o en un cache simple, guardar:
const ULTIMAS_POSES_USADAS = []; // máximo 5 elementos, FIFO

function seleccionarPoseEvitandoRepeticion(posesCompatibles) {
  const disponibles = posesCompatibles.filter(
    pose => !ULTIMAS_POSES_USADAS.includes(pose)
  );
  
  // Si todas fueron usadas recientemente, permitir repetir la más 
  // antigua
  const candidatos = disponibles.length > 0 ? disponibles : posesCompatibles;
  
  const elegida = candidatos[Math.floor(Math.random() * candidatos.length)];
  
  // Actualizar memoria
  ULTIMAS_POSES_USADAS.push(elegida);
  if (ULTIMAS_POSES_USADAS.length > 5) {
    ULTIMAS_POSES_USADAS.shift();
  }
  
  return elegida;
}
```

PASO 4: INCORPORAR LA POSE EN EL PROMPT DE GEMINI

Cuando construyas el prompt de la portada del carrusel, inyectar 
la descripción de la pose seleccionada en el bloque <scene_description>:

```
<scene_description>
[DESCRIPCIÓN DE LA ESCENA ORIGINAL]

CHARACTER POSE FOR THIS COVER (mandatory): 
[descripcion de la pose seleccionada del banco]

The character must adopt this specific pose. Do NOT default to 
"pointing at laptop" or "arm extended right" if the pose above 
specifies something different.
</scene_description>
```

```
The character MUST follow the pose described above. 
AVOID these overused poses unless explicitly requested:
- Body 3/4 right with arm extended pointing
- Body 3/4 looking at laptop screen
- Default "presenter" stance

If the requested pose is "arms crossed", the character's arms MUST 
be crossed (not pointing). If the pose is "shocked", both paws must 
be near the face (not pointing). Verify the pose before finalizing.
```
