1. Generar identificadores de acceso
Añade una cuenta de Instagram para generar identificadores de acceso y configurar suscripciones a webhooks. Antes de continuar, asegúrate de asignarle a la cuenta el rol de tester de Instagram en la pestaña Roles.
2. Configurar Webhooks
Configura una URL de webhook personalizada o usa servicios de ayuda para configurar un extremo. Más información
Para recibir webhooks, el modo de aplicación debe estar en "Live".

3. Configura el inicio de sesión como negocio de Instagram
Proporciona una forma segura de que las empresas concedan permisos a tu aplicación para acceder a los datos con el inicio de sesión de empresa.
4. Completa la revisión de la aplicación
Instagram requiere que se complete correctamente el proceso de revisión de la aplicación para que esta pueda acceder a los datos en directo. Realiza el proceso de revisión para obtener acceso avanzado a los permisos de Instagram. Envía tu solicitud de revisión cuanto lo tengas todo listo.
