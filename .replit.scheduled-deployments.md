# Scheduled deployments (production cron)

WebMakerLatam ships its production cron jobs as Replit Scheduled
Deployments. Configure each one from the Deploy tab → "Scheduled" so the
job runs in the same managed environment that owns the secrets.

## Daily DB backup

- Command: `./scripts/backup-db.sh`
- Schedule: `0 3 * * *` (daily, 03:00 UTC)
- Required env: `DATABASE_URL` (already provisioned).
- Optional env (off-host upload): `BACKUP_S3_URI`, `AWS_ACCESS_KEY_ID`,
  `AWS_SECRET_ACCESS_KEY`, `AWS_DEFAULT_REGION`.
- Retention: `BACKUP_RETENTION_DAYS` (default 7).

## Restore (verified manually)

```
gunzip -c backups/webmaker-YYYYMMDD-HHMMSS.sql.gz | psql "$DATABASE_URL"
```

After restore, run `pnpm --filter @workspace/api-server exec tsx
./scripts/health-check.ts` (if present) or verify via `GET /api/health`
that the server boots against the restored data.
